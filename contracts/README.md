# API Contracts

`openapi.yaml` is the authoritative OpenAPI 3.1.0 contract defining request/response schemas, paths, status codes, and error details for UC001-UC009 plus the timetable conflict and tuition/receipt APIs.

`api-types.ts` provides the shared TypeScript interfaces corresponding to the contract. This task updates the contract/types for backend timetable and tuition APIs without implementing or changing frontend screens.
