# UC007 - Xem thời khóa biểu sinh viên

- Actor: STUDENT.
- API: `GET /api/semesters/current`, `GET /api/students/me/timetable?semesterId=...&week=...`.
- Mặc định tuần từ `currentWeek`; chuyển tuần sẽ truy vấn lại backend.
- Lưới theo `date`, `dayOfWeek` (2-8), `startPeriod`-`endPeriod` (tiết 1-12).
- Không gửi studentId; server lấy danh tính từ JWT.
- `INVALID_WEEK` hiển thị lỗi và dùng tuần hợp lệ/currentWeek khi response cung cấp. Bảng quy đổi tiết sang giờ chưa chốt.
