# UC009 - Xem roster lớp giảng viên phụ trách

- Actor: LECTURER.
- API: `GET /api/lecturers/me/sections`, `GET /api/sections/{id}/students`.
- Mục tiêu: mở danh sách sinh viên của lớp do giảng viên hiện tại phụ trách.
- Server kiểm tra quyền sở hữu lớp; UI không thay thế kiểm tra backend.
- Query phân trang/response roster chưa có trong tóm tắt; chờ OpenAPI.
