# UC004 - Xác thực phiên và kiểm tra quyền sinh viên

- Actor: STUDENT session; được include bởi UC005, UC006, UC007.
- Mục tiêu: xác nhận JWT hợp lệ và quyền sở hữu danh tính sinh viên.
- Quy tắc: API `/me` lấy studentId từ token; client không gửi studentId. Security filter kiểm tra role và service kiểm tra quyền sở hữu.
- UI: route guard chỉ cải thiện trải nghiệm; backend là nơi thực thi quyền.
- Trạng thái: 401 xóa token và về login; 403 hiển thị từ chối truy cập nhưng giữ phiên.
